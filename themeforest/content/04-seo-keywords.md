# 04 · Search keywords (ThemeForest + Google)

## How ThemeForest search works

1. **Item name** — strongest signal. Words in the name match almost every search.
2. **Tags** — 15 slots, exact phrases (`mega menu` matches “mega menu”, not “megamenu”).
3. **Category / attributes** — the filters in the left column (Shopify version, columns, browsers).
4. **Sales, rating and recency** — “Best sellers” and “Recently updated”. Version 2.0 as an update
   of the existing item moves it to the top of “Recently updated” and keeps its sales history.

The description is mostly read by Google, so long-tail phrases go in headings and the first paragraph.

## Rules

- Write keywords as buyers type them; one natural mention per section beats repeating them.
- Never use other item names or “Envato best seller” in name, tags or text.
- Only add a niche to the **name** when a store design for it ships.
- When a new design ships: add it to the name, swap a reserve tag for its niche, add an `<h3>`
  block under *Store designs included* and a changelog line.
