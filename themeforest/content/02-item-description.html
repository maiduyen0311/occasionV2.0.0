What's new in Occasion 2.0

Occasion 1.x (2018–2019) was a sectioned Shopify theme built on jQuery, Bootstrap 4 and the Slick slider. Version 2.0 is a complete rebuild, not a patch:

  • Online Store 2.0: JSON templates, sections and app blocks on every page (product, collection, cart, blog, pages), not only the homepage.
  • New code base: no jQuery and no carousel library; vanilla JavaScript modules and one compiled stylesheet. Bootstrap 5 grid only.
  • Store designs rebuilt: Super Market → Occasion, Shopping → Home Fashion #1, Fashion → Home Fashion #2. The Kids design returns in a later 2.x update.
  • New quick view with gallery, color swatches, sizes and add to cart.
  • Wishlist and compare pages, add-to-cart and wishlist popups, mini cart dropdown.
  • Bundle discount (“Buy 3 get 20% OFF”), daily deals with countdown and stock bars, sales popup.
  • Shopify filters (Search & Discovery) instead of tag filtering; grid 2 / 3 / 4 columns or list view, “Show more” loading.
  • 31 storefront languages and currency / language pickers with flags.
  • Shopify essentials: predictive search, selling plans, Shop Pay Installments, pickup availability, gift card recipient form, accelerated checkout.

Installation

We advise reading the Shopify Help Center on themes: it explains the Shopify platform and the theme editor. The full steps, with screenshots, are in the documentation included in the package.

  1. Download the package from your ThemeForest Downloads page (“All files & documentation”) and extract it.
  2. Open the occasion-v2.0.0 › themes folder and pick the design you want:
    • Occasion: occasion-theme-v2.0.0.zip
    • Home Fashion #1: occasion-fashion-1-theme-v2.0.0.zip
    • Home Fashion #2: occasion-fashion-2-theme-v2.0.0.zip
  3. In Shopify admin: Online Store → Themes → Add theme → Upload zip file. Do not unzip the theme file.
  4. Click Customize and follow the setup guide of your design in documentation/index.html.

Frequently asked questions

I bought Occasion 1.x. Do I get 2.0?

Yes, for free. Download it from your Downloads page and install it as a new theme: your products, collections, menus and pages stay; the homepage is set up again with the guide of your design.

I use the Kids design of 1.x.

Occasion Kids is being rebuilt for 2.0 and will come in a later free update. Until then, keep your current theme published; nothing changes in your live store when the item is updated.

Is Occasion an Online Store 2.0 theme?

Yes. It uses JSON templates, Sections Everywhere and app blocks, so you can add sections to any page.

Can I use all three store designs?

Yes. One license covers one Shopify store, and you can install any design of the package on that store and switch at any time.

Do I need to know code?

No. Everything is edited in the Shopify theme editor. For small style changes, use the Custom CSS field in Theme settings.

Do I need apps for wishlist, compare, quick view or bundles?

No. They are built into the theme. Bundles use a standard Shopify automatic discount, explained in the documentation.
