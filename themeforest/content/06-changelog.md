# 06 · Changelog

Public changelog for the item description (the `Changelog` block at the end of
`02-item-description.html`) and the Envato “item update” note. Keep it in sync with
`documentation/help.html#changelog`.

Format: newest first, version + date, one line per change, prefixed `NEW` / `IMPROVED` / `FIXED`.

## Version 2.0.0 — October 2026 (complete rebuild)

```
NEW      Rebuilt for Shopify Online Store 2.0: JSON templates, sections everywhere, app blocks
NEW      Store designs rebuilt: Super Market -> Occasion, Shopping -> Home Fashion #1 (demo in
         5 languages), Fashion -> Home Fashion #2. Kids follows in a later 2.x update
NEW      One installable theme zip per store design
NEW      Three header layouts; category sidebar with 4 mega menu styles; banner mega menus
NEW      Quick view with gallery, swatches and sizes
NEW      Wishlist and compare pages, add-to-cart and wishlist popups, mini cart dropdown
NEW      Bundle discount “Buy 3 get 20% OFF” on the product page and in deals
NEW      Daily deals (carousel or vertical) with countdown and stock bars
NEW      Sales popup, newsletter popup (4 layouts), free shipping bar, size guide, cookie consent
NEW      Shopify filters, grid 2 / 3 / 4 columns or list view, “Show more” loading
NEW      Card styles: round buttons or action bar, round or tag labels, buttons under cards
NEW      Selling plans, Shop Pay Installments, pickup availability, gift card recipient form,
         unit prices, accelerated checkout option
NEW      31 storefront languages, currency and language pickers with flags
IMPROVED jQuery and Slick removed: vanilla JavaScript modules and one compiled stylesheet
IMPROVED Responsive, lazy-loaded images
IMPROVED Multi-page documentation with a setup guide for each design
```

Upgrade note for 1.x buyers: install 2.0 as a new theme. Store data (products, collections,
menus, pages, blog posts) stays; theme settings of 1.x are not carried over.
