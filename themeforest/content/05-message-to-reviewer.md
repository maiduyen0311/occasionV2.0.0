## A · Update of the existing Occasion item (2.0.0)

The form asks for “a brief description of any changes you have made”:

```
Hello,

This update brings Occasion to version 2.0.0, a complete rebuild for Shopify Online Store 2.0
(version 1.x was a 2018 sectioned theme built on jQuery and Slick). Free for existing buyers.

What changed:
- Rebuilt on Online Store 2.0: JSON templates, sections and app blocks on every page.
- jQuery and Slick removed: vanilla JavaScript modules, one compiled stylesheet.
- Store designs rebuilt: Super Market -> Occasion, Shopping -> Home Fashion #1, Fashion -> Home
  Fashion #2 (Kids follows in a later update). The package now has 3 installable theme zips
  (themes/ folder) and an offline documentation (documentation/index.html).
- Built in: mega menus, quick view, wishlist and compare pages, add-to-cart popup, mini cart,
  bundle discount, daily deals, sales popup, newsletter popup, cookie consent.
- Shopify features: filters, predictive search, selling plans, Shop Pay Installments, pickup
  availability, gift card recipient form, 31 storefront languages.
- Each theme zip passes Shopify Theme Check with 0 errors.
- New description, preview images, tags and changelog.

Live preview: https://iphoenixthemes.com/themes/occasion/
Demos (no password):
- Occasion: https://occasion-demo.myshopify.com/
- Home Fashion #1: https://occasion-demo-1.myshopify.com/
- Home Fashion #2: https://occasion-demo-2.myshopify.com/

Demo images are not included in the download.

Thank you for your time.
iPhoenix Themes — support@iphoenixthemes.com
```
