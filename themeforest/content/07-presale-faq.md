# 07 · Pre-sale answers (Comments tab)

Ready-made replies for the item **Comments** tab. Adapt names and links, keep them short.

---

**I bought Occasion before. Is 2.0 free for me?**
> Yes, updates are free. Download 2.0 from your Downloads page and install it as a new theme next to your current one. Products, collections, menus and pages stay; set up the homepage with the guide of your design, preview, then publish.

**Will my 1.x settings move to 2.0?**
> No. 2.0 is a full rebuild on Online Store 2.0, so the theme settings and sections are new. Your store data is not touched. The documentation shows how each demo is set up.

**Does it work with Online Store 2.0 / Sections Everywhere?**
> Yes. Occasion 2.0 uses JSON templates, sections on every page and app blocks.

**Which Shopify plan do I need?**
> Any plan: Basic, Shopify, Advanced and Plus.

**Can I use all three designs?**
> Yes. One license covers one store, and you can install any design of the package on that store and switch whenever you like.

**Do I need apps for wishlist, compare, quick view, mega menu or bundles?**
> No, they are built into the theme and set up in the theme editor. Bundles use a Shopify automatic discount (explained in the documentation).

**Will my store look exactly like the demo?**
> Layouts and settings are inside each theme zip, and the documentation lists the collections, menus and image sizes of each demo. Demo photos are for preview only and are not included.

**Is the theme translated / does it support multiple currencies?**
> It includes 31 storefront languages and currency / language pickers that work with Shopify Markets.

**Does it support product reviews and filters?**
> Yes. Filters use the free Shopify Search & Discovery app; star ratings work with any reviews app that writes the standard rating metafields (for example Judge.me).

**Is it fast?**
> It uses no jQuery and no carousel libraries, one compiled stylesheet and lazy-loaded responsive images. Final speed also depends on your apps and images.

**Do you offer customization?**
> Support covers theme features, setup questions and bug fixes. Custom code work is not included. Small style changes can go in Theme settings › Custom CSS.

**How do I get support?**
> Use the Support tab of this item or email support@iphoenixthemes.com with your purchase code, store URL and a screenshot. We reply within 1–2 business days (Monday–Friday).
