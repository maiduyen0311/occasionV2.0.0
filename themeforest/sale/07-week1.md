## A. Trả lời bổ sung các bình luận cũ

**cvs7 — “How to enable this Hurry sales ends timer in home and product page”**
```
Update for Occasion 2.0: the countdown timer is in the Deal of the week, Daily deals and Flash deals sections.
In Customize, add one of them to the home page and set the end date. On the product page, the
"Hurry! Only X left" stock bar is in the Product information section settings.
```

**HolidayExperts — “can i put 6 daily deals in the page or only limited to 2?”**
```
Update for Occasion 2.0: the Daily deals section takes up to 6 products, and Flash deals shows products from
any collection you choose, with the number of products as a setting. You can also add the section more than once.
```

**Mastersupplier — “I want to make a stable Header”**
```
Update for Occasion 2.0: the header and menu bar stay at the top while scrolling, out of the box. The product
page also has an optional sticky Add to cart bar.
```

**nachumi_e / Farid123 — ảnh collection không hiện**
```
Update for Occasion 2.0: the Collection banner section can use each collection's own image. Set the image in
Shopify admin > Products > Collections, then in Customize choose the collection image as the banner source.
```

**studiohoodies — microdata**
```
Done in Occasion 2.0: product pages output Product structured data (JSON-LD) for Google.
```

**nasan — custom swatches**
```
Update for Occasion 2.0: color swatches are built in on product cards and the product page.
```

Không cần trả lời các bình luận khen (đã cảm ơn).

## D. Điểm PageSpeed cho mô tả

Ngày 3/11 API PageSpeed miễn phí đã hết lượt nên chưa đo được. Đo tay tại https://pagespeed.web.dev/ cho
`https://occasion-demo.myshopify.com/` (Mobile + Desktop), chụp màn hình. Chỉ đưa vào mô tả nếu điểm tốt
(mobile ≥ 70), ghi ngày đo. Gửi số cho Claude để thêm vào description.
