Checklists, answers to common questions and how to get support.

Launch checklist

  • All demo text replaced (top bar phone and email, copyright, services bar, banners).
  • Every banner and logo uploaded; no grey placeholders left.
  • Flash deal end date is in the future.
  • Menus link to real collections and pages; Wishlist and Compare pages exist.
  • Demo urgency and social-proof content replaced or turned off.
  • Policies created and linked in the footer.
  • Tested on a phone: menu, search, mini cart, product options, checkout.
  • Placed a test order (Settings → Payments → test mode, or Bogus Gateway on development stores).
  • Published the theme: Online Store → Themes → … → Publish.

Accessibility

The themes are built with WCAG 2.1 AA in mind: keyboard navigation with visible focus rings, labelled icons and buttons, a skip link, hidden slides removed from the tab order, and color settings that keep text readable on light accents. Text contrast depends on the colors you choose:

  • Text needs a contrast of at least 4.5 : 1 with its background (3 : 1 for large text). Check with any online contrast checker.
  • With a light accent (lime, yellow, pastel), set Theme settings → Text on accent color to a dark color and Accent text on light backgrounds to a deeper shade of the accent.
  • Give every image an alt text (click the image in the editor → Edit), and fill in banner headings or link texts: they become the name read by screen readers.
  • Keep popups dismissible and turn off demo urgency content you cannot back up.
  • Top Market demo colors: white text on the brand oranges #f05d17 and #dc5414 reaches about 3.3 : 1 and 3.9 : 1: enough for large text (3 : 1) but not for small text (4.5 : 1). For strict AA, use a deeper orange such as #c2410c in Top Market — Colors and the Header / Navigation bar colors, green #3f7d1c for the “NEW” label and eyebrows, and #9a6b00 for gold tags. Haley’s default colors pass AA.

FAQ & troubleshooting

Banners show grey placeholders after installing.

Demo photos are not included. Upload your own in each section (see Image sizes).

A product section is empty.

Select a collection in the section settings and make sure it contains active products available on the Online Store channel.

The mega menu does not open for a category.

The category needs level-2 / level-3 links, and a Mega menu block whose Category menu title matches the menu item title exactly (including the apostrophe in Women's).

Color dots are grey.

Connect the Color option to Shopify's Color metafield so each value has a color (see Color swatches).

The product image doesn't change when I pick a color.

Assign an image to each variant (Variant images).

Filters are missing on collection pages.

Install Search & Discovery and add filters. Filters listed in Hidden filters are not shown.

Stars show 0 or no reviews.

Install a reviews app that fills reviews.rating and reviews.rating_count, or turn ratings off in the section settings.

The countdown shows 0.

The end date has passed. Set a new Offer end date in Home flash deals.

The wishlist is empty on another device.

Wishlist and compare are stored in the browser. Use Share wishlist to open the same list elsewhere.

The currency switcher shows only one currency.

Enable local currencies in Settings → Markets and list them in Header → Currency options.

Login / register pages look different.

Switch to classic customer accounts in Settings → Customer accounts.

Custom CSS

To change a style without editing theme files, open Online Store → Themes → Customize → Theme settings → Custom CSS (whole store) or the Custom CSS field at the bottom of any section (that section only). Your CSS is kept when you update the theme.

.tm-btn { border-radius: 0; }
Don't edit assets/styles.css or assets/common.js in the code editor. They are compressed build files and are replaced when you install a new theme version.

Support

Support is provided through the Support tab on the item page on ThemeForest or by email at support@iphoenixthemes.com. Please include your purchase code (where to find it), your store URL, the page where the issue happens and screenshots.

  • Included: help with theme features, bug fixes and setup questions.
  • Not included: custom code changes, third-party app issues and store content.

Response time: 1–2 business days (Monday–Friday).
