Getting started

The steps on this page are the same for every theme in the package.

Package contents

Unzip the file you downloaded from ThemeForest. Inside you will find:

File / folderWhat it is
themes/One installable Shopify theme per design: occasion-theme-v2.0.0.zip, occasion-fashion-1-theme-v2.0.0.zip, occasion-fashion-2-theme-v2.0.0.zip. Upload one of these files to Shopify. Do not unzip it.

“Zip file is not a valid theme”? You uploaded the whole ThemeForest download. Upload only one file from the themes/ folder.

Requirements

  • A Shopify store on any plan. The theme uses Online Store 2.0 JSON templates.
  • For the styled login, register and account pages: classic customer accounts (Settings → Customer accounts). New customer accounts use pages hosted by Shopify.
  • Recommended free apps: Shopify Search & Discovery for collection filters, and a reviews app that fills the standard reviews.rating metafields (for example Judge.me) for star ratings.
  • Browsers: latest two versions of Chrome, Safari, Firefox and Edge; iOS Safari and Android Chrome.

Install a theme

  1. In your Shopify admin go to Online Store → Themes.
  2. In Theme library click Add theme → Upload zip file.
  3. Select the zip of the theme you chose from the themes/ folder, for example occasion-fashion-2-theme-v2.0.0.zip, and click Upload. It takes about a minute.
  4. Click Customize on the new theme to open the theme editor.
  5. Follow the setup guide of your theme (Occasion, Home Fashion #1, Home Fashion #2).
  6. When everything is ready, click … → Publish to make it your live theme.
Tip: uploading never touches your live theme. Set the new theme up in the background and publish when it is ready.

Your purchase code

Every ThemeForest purchase comes with a purchase code (license key). It proves that you own a license and is required when you ask for support.

Installing does not need the code. Upload the theme zip as described in Install a theme; nothing in the theme is locked.

Find your purchase code

  1. Sign in to ThemeForest with the account you bought the theme with.
  2. Open your username menu (top right) and click Downloads.
  3. Find Occasion in the list and click Download.
  4. Choose License certificate & purchase code (PDF or text). The code is in the file, after Item Purchase Code.

A purchase code looks like this: 1a2b3c4d-5e6f-7a8b-9c0d-1e2f3a4b5c6d (32 letters and digits in five groups).

Use your purchase code

  • Support: paste the code in your message on the item's Support tab or in your email to support@iphoenixthemes.com, together with your store URL (your-store.myshopify.com). See Support.
  • Updates: new versions are always in your ThemeForest Downloads; keep the code with your store records.
Keep it private. One purchase code covers one Shopify store (Regular or Extended license). Do not share it or post it in public comments. For another store, buy another license.

About demo content

A theme zip contains the design and layout of its demo: colors, fonts, header, which sections appear on each page, in which order, with which text. It does not contain products, collections, menus, pages, blog posts or photos: Shopify stores those in your admin, not in the theme.

Included in the theme zipYou create in the admin
Theme settings (colors, fonts, cards, cart, popups)Products, variants, photos and metafields
Header, footer and navigation layoutCollections
Homepage sections and their textMenus
Page templates (about, contact, FAQ, lookbook, wishlist, compare…)Pages, blog posts, policies and discounts

After installing you will see grey placeholders where the demo shows a photo, and empty product sections until you select your own collections. Each theme page lists exactly what to create and which image size to upload for every spot.

Demo photos are for preview only and are not included in the package. Use your own photos or a licensed stock library.

Switch to another theme

Your products, collections, menus, pages and uploaded files stay in the admin, so switching only changes the design.

  1. Upload the other theme's zip (Install a theme). It arrives as a new unpublished theme.
  2. Open it in the theme editor and select your menus and collections in the header, navigation and homepage sections (each theme page tells you where).
  3. Preview, then publish it. Your previous theme stays in the theme library, so you can switch back.
Settings are per theme. Changes made in the theme editor of one theme are not copied to the other.

Updating the theme

  1. Download the latest version from your ThemeForest Downloads page.
  2. Upload the new theme zip as in Install the theme. It arrives as a new, unpublished theme.
  3. Copy your settings: in the old theme open … → Edit code, copy config/settings_data.json, the templates you customized, and sections/header-group.json / footer-group.json into the new theme. Or re-apply them in the editor.
  4. Preview, then publish the new version.
Tip: your products, collections, menus, pages and uploaded files live in the admin and are kept automatically.
