How it works

  1. Choose a theme above and open its live demo to compare.
  2. Install it: upload that theme's zip file in your Shopify admin. See Install a theme.
  3. Add your content in the Shopify admin: products, collections, menus, pages. See Step 1 · Shopify admin.
  4. Follow the theme's page (Occasion, Home Fashion #1 or Home Fashion #2): it lists the collections, menus, homepage sections and image sizes of that demo.
  5. Fine-tune and launch with the theme editor guide and the launch checklist.
