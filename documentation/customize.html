Step 2 · Theme editor

Everything you change here is stored in the theme, so it applies to whichever store design you installed.

Theme editor basics

Open it from Online Store → Themes → Customize. The editor has three areas:

  • Left sidebar: the list of sections on the current page, grouped as Header, Template and Footer. Click a section to edit it; click the arrow next to it to see its blocks (slides, banners, tabs…).
  • Page picker at the top: switch between Home page, Products, Collections, Pages, Blogs, Cart and others.
  • Theme settings (the gear / paint-brush icon): global colors, fonts, cart and more.
To…Do this
Add a sectionClick Add section in the group (Template, Header or Footer) and pick it from the list.
Add a block (slide, banner, tab…)Expand the section and click Add block (for example Add Slide).
ReorderDrag the handle (⋮⋮) that appears when you hover a section or block.
Hide without deletingClick the eye icon next to the section or block.
Delete / duplicateOpen the section, scroll to the bottom and click Remove section, or use the … menu to duplicate.
Upload an imageIn an image setting click Select image → Upload, or pick one from your Files.
Link somewhereClick a link field and search for a product, collection, page or blog, or paste any URL.
Preview on mobileUse the device icons in the top bar.
UndoCtrl / ⌘ + Z, or the undo arrow in the top bar.
Remember to Save (top right). Changes are not live until you save, and on an unpublished theme they are not visible to shoppers until you publish.

Accent colours and product cards

  • Text on accent color and Accent text on light backgrounds: set these when the accent is very light (lime, yellow) so labels, buttons and links stay readable (WCAG AA).
  • Card layout: Classic or Minimal (reviews, colours, title, price; quick view / wishlist / cart on hover). Minimal card label style: white label or accent label.
  • Corner style: theme default or square corners everywhere.

Header

In the editor, click Header in the Header group. Its settings are split into groups:

Header top (the thin bar)

  • Background / Text color (demo: #dc5414 / white).
  • Help label, Contact phone and Contact email on the left and right.
  • Utility link: label, URL and icon of the “Track Order” link. Pick an icon from the library or upload your own.
  • Show currency selector and Currency options: the list of currencies with the country whose flag is shown, for example USD:US, EUR:DE, GBP:GB. Currencies must also be enabled in Markets (see Languages).
  • Show language selector: lists the languages published in Settings → Languages.

Header middle

  • Background / Text and icon color.
  • Logo: upload a Logo image, or leave it empty to use the two-line text logo (TOP / market) written with the script font.
  • Search: placeholder text, the “All Categories” label and the Category menu. Select your Shop By Categories menu so shoppers can limit a search to one category.
  • Utility links: show or hide Account, Compare, Wishlist and Cart; rename their labels; turn the account dropdown (login form) on or off; change the Wishlist and Compare page links if you used other page handles.

Desktop layout

Header → Desktop layout offers two layouts:

  • Classic: logo, wide search and icons, with the Navigation bar (Shop by Categories + main menu) below.
  • Inline: logo, menu, compact search and icons in one row. Choose the Menu; level-2 links open a dropdown, and level-3 links turn it into a mega panel. Menu badges adds labels such as Sale|HOT|#d64545 (one per line: menu title|label|color). Then turn off Navigation → Show desktop bar.

Left side of the top bar shows either the help label and phone or an announcement with a link.

Tip: the navigation bar under the header (Shop by Categories, main menu, promotion link) is a separate section called Navigation, described next.

Header in one row & mega menus

Set Header → Layout to Logo, menu and icons in one row (used by Haley). The menu then comes from Menu in the same section, and Navigation → Show desktop bar can be turned off.

Mega menus in the header row

  1. Expand Header and click Add block → Mega menu (menu row).
  2. In Menu link title type the top-level menu title exactly, for example Shop.
  3. Choose a Style and fill in its settings:

Navigation & mega menus

Section settings

  1. Click Navigation in the Header group.
  2. Set the bar colors and the Categories button label (“SHOP BY CATEGORIES”).
  3. Categories menu: select Shop By Categories (built in Menus).
  4. Menu: select Main menu for the links in the orange bar.
  5. Promotion: the gift-icon link on the right (“Big promotion now!”) with its URL.
Which rows open a panel? Only categories that have sub-links in the menu, or a Mega menu block: with a block the panel uses that style. Without a block, sub-links that have their own sub-links (3 levels) are listed in columns, and sub-links with none (2 levels) open a short list right beside the hovered category. Categories without either are plain links, and no panel opens while they are hovered.

Add a mega menu to a category

  1. Expand Navigation and click Add block, then choose a Mega menu style (1–4, see the table).
  2. In Category menu title type the level-1 title exactly as in the menu, for example Women's.
  3. Link columns: how many columns the level-2 headings are spread over. For full control use Headings per column, for example 2,2,2 = three columns with two heading groups each.
  4. Fill in the style's extra content (product, banners, cards) and save.
BlockLayoutExtra content
Mega menu style 1Link columns + featured product + promo bannerA product (with rating, swatches and button) and a portrait banner with heading, text, button and colors
Mega menu style 2Wide link columns + 3 image cardsThree small cards, each with title, image and link
Mega menu style 3Link columns + side bannerOne portrait banner with link
Mega menu style 4Link columns + 2 bottom bannersTwo wide banners with links
Category icon—Small icon shown before a category in the sidebar. Menu link title must match the level-1 title.

On phones and tablets

Below 992 px the header becomes one bar: menu button, logo, then Search, Account, Wishlist and Cart icons. Account opens the account page directly and Cart slides in from the right. The menu button opens a drawer with two tabs:

  • Menu: the Main menu (tap + to open sub-links), the promotion link, the help contact from the Header section, and the currency and language pickers.
  • Categories: the Shop by Categories menu, up to 3 levels.

Rename the tabs in Navigation → Mobile menu. Everything else comes from the menus and Header settings you already set.

No mega menu wanted? Leave the category without a mega menu block. It then behaves as a normal link, like Accessories in the demo.

Footer, services bar & popup

Services bar

In the Footer group click Home services bar. Each Service block has an icon (preset or your own image), title, subtitle and optional link. Section settings set the background, text and accent colors and the dividers.

Footer

  1. Add a Link list block for each column and select a menu (demo: Company, Products, Profile, Language).
  2. Add the Newsletter block for the email form. Social icons appear below it (URLs in Theme settings → Social media).
  3. Other blocks: Text column, Image, Brand information (from Theme settings) and Language switcher.
  4. Section settings: copyright text and payment icons (Manual, or Shop enabled to show the payment methods active in your store).

Newsletter signups are saved as customers with marketing consent in Customers.

Newsletter popup

Also in the Footer group. Settings: on or off, all pages or home only, delay, days before showing again, image (810 × 810) and layout, title, text, placeholder, colors and page overlay.

Languages & currencies

  • Languages: add and publish them in Settings → Languages. Translate content with the free Translate & Adapt app. Theme texts can be edited in Online Store → Themes → … → Edit default theme content.
  • Currencies: in Settings → Markets enable local currencies, then list them in Header → Currency options as CODE:COUNTRY pairs (the country sets the flag).
The theme editor uses your default language. Shopify edits and previews theme content only in the store's default language. Set your main language as Default in Settings → Languages before you customize, and translate the other languages with Translate & Adapt.
