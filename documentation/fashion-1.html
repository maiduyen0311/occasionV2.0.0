Home Fashion #1 — fashion store

A fashion store with a centered logo, text links in the top bar, a green All Categories menu with icons and four mega menus, a deals carousel, list view with Add to cart, and the store translated into five languages.

Theme file: occasion-fashion-1-themePoppins 15 pxGreen #96CC66Centered logo header

Overview

Install occasion-fashion-1-theme-v2.0.0.zip (how). Every setting below is already in that file: create the content in the Shopify admin, upload your images and pick them in the theme editor. Shared steps (products, variants, swatches, metafields) are in Step 1 · Shopify admin.

Centered logo

Hotline left, logo centre, underline search right; top bar with text links and the cart icon.

All Categories

Icons with dividers, + / − toggles, four mega menus (compact, icon headings, banners).

Deals & New Items

Daily Deals carousel, Trending Items, New Items tabs.

Five languages

English, French, German, Spanish and Italian, including product texts.
