Collections

Go to Products → Collections → Create collection. A manual collection lets you pick products one by one; an automated one adds products by conditions (for example Tag is equal to flash-deal). Add a collection image: it is used by the category circles and the collection banner.

The demo uses two kinds of collections:

Women's, Men's, Clothing, Shoes, Bags, Accessories, Seasonal wear…Shop by Categories menu, promo banners, collection pages

Tip: give helper collections a handle starting with tm-. The All collections page hides them (Collections list page → Hide collections whose handle starts with), so shoppers only see your real categories. Edit the handle under Search engine listing on the collection page.

Add a section to the homepage

  1. Open the editor. The page picker at the top should say Home page.
  2. In the Template group click Add section.
  3. Pick a section, for example Home promo grid. It is added at the bottom with sample text.
  4. Drag it to the position you want.
  5. Click it to open its settings, then expand it to edit or add blocks.
  6. Click Save.

Two ways to show a banner

Most banner sections have the setting Image already contains text:

  • On: your image is a finished design with the text painted in (like the demo artwork). It fills the banner and links to the banner link. The section's text settings are ignored.
  • Off: the theme builds the banner from its settings: background color, script and bold titles, button, and your image (a cut-out photo works best) on the left or right.

Use On if you have a designer or use Canva; use Off to change text and colors any time without editing images.

Home hero: slider + side banners

  1. Click Home hero → expand it. It holds two kinds of blocks.
  2. Slide (up to 6): Image (1860 × 862, text included in the image), optional Video instead of the image, and Link (the whole slide is clickable). Add slides with Add block → Slide.
  3. Promo banner (up to 3): image (900 × 314) and link. They stack in the column on the right of the slider; keep 2 or 3 so the column is filled.
  4. Section settings: Autoplay and Autoplay speed (seconds), Full width, top and bottom padding.

Home promo grid

  1. Each tile is a Banner block. The demo has 5: one Large tile and four Small tiles.
  2. For each block set Size (large = tall tile on the left, 900 × 1106; small = 900 × 526), Image, Subtitle (“Trendy”), Title (“Women Clother”), Button label and Link (usually a collection).
  3. Text position places the text in a corner or the center of the tile. Without an image, the Background color is used.
  4. Section settings: gap, corner radius and the colors of subtitle, title and button.

Home flash deals

  1. Collection: pick the products on sale (demo: tm-flash-deals). Give them a compare-at price so the discount badge appears.
  2. Offer end date in the format YYYY-MM-DD, for example 2026-12-31. The countdown ends at 11:59 PM store time and then stays at 0, so update the date for each new campaign.
  3. Title (bold words use B in the text editor), Countdown label, number of products and columns.
  4. Show sold progress bar: uses each product's custom.sold_count metafield against the Progress bar capacity.
  5. Accent and border colors; product card options (rating, second image on hover, discount badge).

Home new products

Pick a Collection (demo: tm-new-products, or an automated collection sorted by newest). Set the heading, number of products and columns, the card options, and the View all button label and link. Auto-show NEW badge labels products created in the last 30 days.

Video banner

Two blocks side by side. Mix them as you like:

  • Banner: image (1380 × 500) and link. Turn off Image already contains text to use the background color, script text (“Summer”), bold text (“SALE”) and an optional decorative image.
  • Video: upload a Shopify-hosted video or paste a YouTube / Vimeo URL, add a cover image shown before playing, and optional text.

Home best selling (tabs)

  1. Each tab is a Collection tab block: Tab label (“Clothing”) + Collection. The demo has All, Clothing, Shoe, Bag and Accessories.
  2. Section settings: eyebrow and heading, products per tab (10 = two rows of 5), columns on desktop and mobile, card options, the “+ SEE ALL PRODUCTS” button and the accent color of the active tab. On phones each tab becomes an accordion row; the first one starts open.

Top trending rows (Best of Men / Women / Shoes)

The same section added three times with different presets. Add section → Best of Men (Top Trending), Best of Women or Best of Shoes.

  1. Feature card on the left: image (516 × 936), button label and link, background color. Turn on Feature image already contains text for finished artwork.
  2. Collection and Number of products (4 in the demo) for the products on the right.
  3. Show section title: the demo shows “Top Trending” only on the first row.

Home dual banner

Two Banner blocks side by side, 1380 × 502 each. Each block has an image, link, background color, script eyebrow (“Spring Collection Day”), bold title (“SALE 30%”) and the Image already contains text switch. Section settings: gap and corner radius.

Home brand logos

Add one Logo block per brand: transparent PNG, optional link and alt text. Grayscale logos shows them grey until hovered; Logo height and Gap control the size and spacing.

Home latest news

Pick the Blog (demo: News) and how many articles to show. Choose the card style (classic or editorial) and whether to show image, date, excerpt and “Read more”. Posts come from Blog posts.

Home Instagram

Add one Instagram image block per photo (600 × 800 portrait) with an optional link to the post. Set the heading (“Instagram #TOPMARKET”), your handle and profile URL, columns and gap. The images are uploaded by you, so no Instagram app or login is needed.
