Metafield definitions

Metafields are extra product fields. Occasion reads these. Create the definitions once, then fill them in on each product.

  1. Go to Settings → Custom data → Products and click Add definition.
  2. Create the definitions from the table below. Namespace and key must match exactly.
  3. Save. The fields now appear at the bottom of every product page in the admin, under Metafields.
NameNamespace and keyTypeWhat it does
Badgecustom.badgeSingle line text. Optionally limit to a list of values: new, hot, sale, bestsellerShows a NEW / HOT / SALE / BEST label on product cards. When a product has a compare-at price, the discount badge (for example -22%) is shown instead.
Sold countcustom.sold_countIntegerFills the “Sold” progress bar in Daily deals.
Ratingreviews.rating and reviews.rating_countStandard Shopify definitions (Rating, Integer)Stars and review count. Reviews apps fill these automatically. Without an app, add the standard definitions and type the values in.
Tip: for custom.badge, turn on Limit to preset choices and add the four values. You then pick the badge from a dropdown instead of typing it.

Add products & variants

Product cards, quick view, the product page and the compare page are all built from your product data. Set products up as below to get the same result as the demo: color dots under each card, size buttons, and images that change when a color is picked.

1. Basic details

  1. Go to Products → Add product.
  2. Title and Description. The first 30 words of the description also appear as the short text under the title on the product page, and in the compare table.
  3. Media: upload all photos of the product, including one photo per color. Use square images (1:1, at least 1000 × 1000 px) on a white or light background, like the demo. The first image is the card image; the second one appears when a shopper hovers the card.
  4. Category: pick a Shopify product category, for example Apparel & Accessories › Handbags. The category unlocks color swatches (step 3).
  5. Price and Compare-at price. When the compare-at price is higher, cards show the old price crossed out and a discount badge (-23%).
  6. Under Product organization set Type and Vendor (shown on the product page and the compare page), and add the product to its collections.
  7. Set Status: Active and make sure the Online Store sales channel is selected.

2. Variants: Size and Color

  1. In the Variants card click Add options like size or color.
  2. Option name Size, values for example M, L, XL, XXL. Click Done.
  3. Click Add another option. Option name Color, values for example Black, Gray, Silver. Click Done.
  4. Shopify creates one variant per combination. Set the price, SKU and inventory of each variant (or edit them all at once with Bulk edit).
Option names matter. The theme treats an option as a color when its name contains Color, Colour or Màu. Colors get round swatches on cards and in quick view; every other option gets buttons. The display order of options is set in the theme, not in the admin: Product information → Option display order (Size, Color in the demo) and Theme settings → Quick view → Options to show.

3. Color swatches

Swatch colors come from Shopify's native swatches. To get them:

  1. Set a product Category (step 1).
  2. When you type the option name Color, Shopify offers to connect it to the Color metafield. Accept, then choose the color entries (Black, Gray, Silver…) instead of typing plain text.
  3. Each entry has a color code (or a pattern image). Edit or add entries in Content → Metaobjects → Color.

A plain-text Color option still works. Values show as text buttons on the product page, but the dots on product cards appear grey because they have no color data. Collection filters and the compare page recognise common color names (black, white, red, blue, navy, pink, beige, gold…) and color them anyway.

4. Variant images

  1. In the Variants card click a variant (for example M / Black).
  2. Click the image placeholder and pick the matching photo from the product media. Repeat for each color. With Bulk edit you can assign images to all variants of one color at once.

Result: picking a color on the product page switches the main image and thumbnail; hovering a color dot on a product card swaps the card image, price and discount.

5. Inventory

  • Turn on Track quantity to show In stock / Out of stock and the “Only 36 items left” bar on the product page. Sold-out values appear crossed out.
  • Untracked products use the fallback quantity from Product information → Fallback qty when inventory not tracked.

6. Metafields

At the bottom of the product page, fill in Badge (new / hot / sale / bestseller), Sold count for flash-deal products and, if you do not use a reviews app, the rating. See Metafield definitions.

Gift wrap product (optional)

The cart offers gift wrap as an add-on. Create a simple product called for example Gift Wrap ($10 in the demo), then select it in Theme settings → Cart → Gift wrap product and Cart page → Subtotal → Gift wrap product.

Many products? Use Products → Import with Shopify's CSV template. Put option names in Option1 Name = Size, Option2 Name = Color, and one row per variant with its Variant Image.

Collections

Go to Products → Collections → Create collection. A manual collection lets you pick products one by one; an automated one adds products by conditions (for example Tag is equal to sale). Add a collection image and a short description: they are used by the category circles, the collection banner and the All collections page.

Product sections on the homepage show one collection each, so create the collections your theme's homepage uses first:

Helper collections: collections that only feed a homepage section (for example “Flash deals”) can use a handle starting with tm-. The All collections page hides them (Collections list page → Hide collections whose handle starts with). Edit the handle under Search engine listing.

Blog posts

  1. Go to Content → Blog posts → Create blog post.
  2. Add a title, content, an excerpt (shown on cards) and a featured image. Portrait images (3:4, for example 900 × 1200 px) match the demo cards.
  3. Choose the blog (the demo uses News) and add tags. Tags become the categories in the blog sidebar.

The homepage Home latest news section then shows the newest posts of the selected blog.

Discounts for bundles

The Bundle block (“Buy 3 get 20% OFF”, on the product page and in Deal of the week) lets shoppers add several products at once and previews the discounted total. The discount itself is applied at checkout by Shopify, so create it once:

  1. Go to Discounts → Create discount → Amount off products.
  2. Method: Automatic discount, title for example Buy 3 get 20% off.
  3. Value: 20 %, applies to All products (or the bundle's collection).
  4. Minimum purchase requirements: Minimum quantity of items: 3.
  5. Save. Use the same numbers in the block's Discount preview and Items needed for the discount settings.
