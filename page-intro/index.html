FAQ

Questions before you buy

Anything else? Write to support@iphoenixthemes.com.

Is Occasion an Online Store 2.0 theme?

Yes. JSON templates, sections on every page and app blocks. It is built on the architecture of Shopify Dawn and checked with Shopify Theme Check.

Can I use all three designs?

Yes. Each design is its own theme zip. One license covers one store, and you can install any of the designs on it and switch whenever you like.

Do I need apps for wishlist, compare, quick view or mega menus?

No. They are built into the theme and switched on in the theme editor. The bundle discount uses a standard Shopify automatic discount, explained in the documentation.

Will my store look like the demo?

Layouts and settings ship inside each theme zip, and the documentation shows the collections, menus and image sizes used by every demo. Demo photos are not included.

Do I need to code?

No. Every text, colour, image and link is a setting. For small style changes there is a Custom CSS field.

Where is the documentation?

It comes with the download: open documentation/index.html from the package in any browser, no internet needed. It covers installation, store setup, every section and setting, and a setup guide for each of the three designs.

How do I get support?

Through the Support tab on ThemeForest or support@iphoenixthemes.com. We help with theme features, setup questions and bugs.
